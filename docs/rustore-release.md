# Kinetic Lab — выпуск для RuStore

Отдельная сборка той же игры под Android: пресет **RuStore Android**, формат APK, архитектуры `arm64-v8a` и `armeabi-v7a`, рендер GL Compatibility. Пакет: `build/rustore/KineticLab.apk`. Приложение полностью офлайн: ни одного разрешения, ни одного сетевого запроса, SDK магазина не подключён.

Версия для Яндекс Игр не изменилась: пресет `Yandex Web`, мост `web/bridge.js` и архив `build/kinetic-lab-yandex.zip` работают как раньше. Обе сборки собираются из одного проекта и отличаются только пресетом экспорта и тегом `rustore`.

## Отличия двух сборок

| | Яндекс Игры | RuStore |
| --- | --- | --- |
| Пресет экспорта | `Yandex Web` | `RuStore Android` |
| Мост платформы | `web/bridge.js`, `YaGames.init()` | нет, `JavaScriptBridge` не используется |
| Реклама | полноэкранная между экспериментами | нет; `platform.has_ads()` возвращает `false` |
| Сохранения | `localStorage` браузера | `user://progress.json` во внутренней памяти |
| Язык | `ysdk.environment.i18n.lang` | локаль Android, кнопка **RU / EN** |
| Пауза | события SDK, вкладка, фокус | `APPLICATION_PAUSED` / `APPLICATION_RESUMED` |
| Полный экран | запрос через SDK | immersive mode пресета |
| Выход | игрок закрывает вкладку | кнопка **Выход** в меню и системная «Назад» |
| Ориентация | подсказка повернуть устройство | sensor landscape на уровне приложения |
| Разрешения | — | ни одного, включая `INTERNET` |

Сборка узнаёт себя по тегу `rustore` из `custom_features`: `scripts/platform.gd` по нему выключает рекламу, а `scripts/hud.gd` показывает кнопку выхода. В редакторе тега нет, поэтому мобильная раскладка и сохранение в файл дополнительно опираются на `OS.has_feature("mobile")`.

## Что нужно для сборки

1. **Godot 4.7.1** и **Android export templates** той же версии.
2. **Android SDK** с `build-tools` (нужен `apksigner`) и **JDK 17**. Пути указываются в редакторе: *Editor Settings → Export → Android → Android SDK Path* и *Java SDK Path*. Gradle-сборка не используется, поэтому Android Studio не нужна.
3. **Ключ подписи.** RuStore принимает только подписанный пакет, и все будущие обновления должны быть подписаны тем же ключом — потерянный ключ означает новую карточку в магазине.

```powershell
keytool -genkeypair -v -keystore kinetic-lab.keystore -alias kineticlab -keyalg RSA -keysize 4096 -validity 10000
```

Храните `.keystore` и пароль вне репозитория: `.gitignore` уже исключает `*.keystore`, `*.jks` и `export_credentials.cfg`. Скрипт сборки читает ключ из переменных окружения, чтобы пароль не попадал в историю команд.

```powershell
$env:GODOT_ANDROID_KEYSTORE_RELEASE_PATH = 'C:\keys\kinetic-lab.keystore'
$env:GODOT_ANDROID_KEYSTORE_RELEASE_USER = 'kineticlab'
$env:GODOT_ANDROID_KEYSTORE_RELEASE_PASSWORD = (Read-Host -AsSecureString | ConvertFrom-SecureString -AsPlainText)
powershell.exe -NoProfile -ExecutionPolicy Bypass -File tools/build_rustore.ps1
```

`build_rustore.ps1` импортирует ресурсы, прогоняет проверку физики, проверку роботов и проверку пакета, экспортирует APK и печатает его размер. Ключ `-Unsigned` собирает неподписанный пакет для локальной установки — в магазин такой файл не принимают. Ключ `-SkipTests` пропускает проверки.

Иконки запуска генерируются из той же геометрии, что и `assets/icon.svg`:

```powershell
node tools/android_icons.mjs
```

Скрипт создаёт `assets/android/icon-192.png`, адаптивные слои 432×432 (передний план, фон, монохром) и `store-icon-512.png` для карточки магазина. Повторный запуск нужен только после изменения `assets/icon.svg`.

## Настройки карточки

- **Название:** Kinetic Lab. Проверьте, что имя свободно в каталоге.
- **Идентификатор приложения:** `com.kineticlab.game`. Значение задаётся в `export_presets.cfg` (`package/unique_name`) и должно совпадать с зарегистрированным в консоли RuStore. После первой публикации идентификатор изменить нельзя.
- **Версия:** `versionName` 1.0.0, `versionCode` 1. Каждое обновление должно увеличивать `versionCode`; `versionName` синхронизирован с `config/version` в `project.godot`, и проверка `tests/rustore.test.cjs` следит за этим.
- **Категория:** игры, симуляторы или казуальные — выберите доступные в консоли.
- **Языки карточки:** русский и английский, тексты ниже.
- **Иконка:** `assets/android/store-icon-512.png` (512×512, PNG).
- **Скриншоты:** минимум три горизонтальных снимка с устройства или эмулятора. Снимки для Яндекс Игр подходят по содержанию, но требования к размерам проверьте в консоли.
- **Возрастной рейтинг:** заполняется анкетой. В игре есть стилизованное оружие, импульсы и взрывы, направленные на роботов; нет крови, людей, животных, реалистичных травм, азартных игр и общения между игроками. Разумная заявка — **12+**; окончательное решение принимает модерация.
- **Монетизация:** нет. Ни покупок, ни рекламы, ни подписок, поэтому SDK RuStore (платежи, отзывы, обновления) намеренно не подключён — это оставляет приложение полностью офлайн.
- **Сбор данных:** приложение не собирает, не передаёт и не хранит персональные данные. Прогресс лежит только на устройстве в `user://progress.json` и удаляется вместе с приложением (`user_data_backup/allow=false`). Если консоль всё же требует ссылку на политику конфиденциальности, в ней достаточно зафиксировать отсутствие сбора данных.

## Требования магазина и их реализация

| Требование | Реализация |
| --- | --- |
| Подписанный релизный пакет | `package/signed=true`, ключ из переменных окружения, проверка в `build_rustore.ps1` |
| Поддержка 64-битных устройств | `architectures/arm64-v8a=true` рядом с `armeabi-v7a` |
| Только необходимые разрешения | все `permissions/*` выключены, `INTERNET` в том числе; проверяется тестом |
| Работа без сети | нет сетевого кода, нет SDK, нет сторонних ресурсов |
| Системная кнопка «Назад» | закрывает подсказку, отменяет размещение, возвращает в меню; выход из меню по второму нажатию |
| Сворачивание и звонок | `APPLICATION_PAUSED` ставит игру и звук на паузу и сохраняет сцену |
| Корректный выход | кнопка **Выход** в меню и закрытие окна сохраняют прогресс до завершения |
| Ориентация | sensor landscape, immersive mode |
| Иконка приложения | адаптивная: передний план, фон и монохромный слой 432×432 |
| Данные пользователя | локальный файл, резервное копирование выключено |
| Содержание | авторские векторные рисунки, процедурные звуки, без заимствованных ассетов |

## Проверка перед отправкой

Автоматические проверки в этом репозитории разбирают конфигурацию и логику, но **не заменяют запуск на устройстве**: в среде, где готовилась сборка, не было ни Godot, ни Android SDK, поэтому APK ни разу не собирался и не устанавливался. Всё, что ниже, нужно пройти вручную перед первой отправкой.

1. Собрать подписанный APK и установить его на настоящее устройство с Android (проверьте и самое слабое из целевых).
2. Первый запуск: игра открывается горизонтально, на весь экран, без запроса разрешений. В настройках приложения список разрешений должен быть пуст.
3. Управление касаниями: создание объектов, «Захват», инструменты, поворот, кнопки передач, экранные кнопки в мобильной раскладке.
4. Свернуть игру, принять звонок, вернуться: физика и звук на паузе, сцена восстановлена, прогресс не потерян.
5. «Назад» из лаборатории возвращает в меню, «Назад» в меню просит подтверждение и закрывает игру. Кнопка **Выход** делает то же самое.
6. Перезапустить приложение: сцена, открытия, язык и настройка звука сохранились. Проверить смену языка кнопкой **RU / EN**.
7. Проверить производительность на слабом устройстве в тяжёлых сценах (цепная реакция, много тел) и нагрев при длительной игре.
8. Убедиться, что `versionCode` больше, чем у предыдущей загрузки, и загрузить пакет в консоль RuStore на модерацию.

Игра не загружалась в консоль RuStore и не проходила модерацию. Решение о публикации принимает магазин.

## Тексты карточки

### Русский — короткое описание

Физическая песочница: роботы, конструкции, взрывы и 26 экспериментов.

### Русский — полное описание

Kinetic Lab — лаборатория, в которой можно проверить самые необычные идеи. Выбирайте среди 11 моделей роботов, стройте конструкции, соединяйте предметы пружинами, запускайте двигатели и наблюдайте за цепными взрывами. Каждый робот собран из подвижных физических деталей, а специальные модели умеют прыгать, бегать, притягивать предметы, бить разрядом и чинить соседей.

Двадцать шесть готовых экспериментов помогут начать: свободная песочница, башня, цепная реакция, трасса, риф, летающая платформа и другие. В каталоге 179 объектов: детали конструктора, гаджеты, игрушки с разной физикой, стихии, машины и оружие. Управляйте гравитацией, замедляйте время, замораживайте объекты и открывайте одиннадцать достижений инженера.

Игра работает полностью офлайн: без интернета, рекламы, покупок и регистрации. Прогресс хранится только на вашем устройстве. Сохраняйте лабораторию и продолжайте эксперимент когда угодно.

### Русский — как играть

Выберите предмет в каталоге и коснитесь свободного места, чтобы создать его. Инструмент «Захват» перетаскивает и бросает предметы. Попробуйте импульс, взрыв, заморозку и связь двух объектов. Выбранный двигатель включается кнопкой «Пуск»; той же кнопкой ремонтируется робот. Экранные кнопки меняют инструменты, масштаб и положение камеры. Кнопка «Сохранить» записывает сцену, достижения сохраняются сами.

### English — short description

A physics sandbox: robots, contraptions, explosions and 26 experiments.

### English — full description

Kinetic Lab is a physics laboratory for your wildest ideas. Choose from 11 robot models, build structures, connect objects with springs, fire up thrusters and set off chain reactions. Every robot is made of moving physical parts, while special models can jump, run, attract objects, discharge electricity and repair nearby robots.

Explore 26 ready-made experiments — a sandbox, a tower, a chain reaction, a relay track, a reef, a flying platform and more — with 179 objects in the catalog. Toggle gravity, slow down time, freeze objects and earn 11 engineering discoveries.

The game runs completely offline: no internet, no ads, no purchases and no sign-up. Your progress stays on your device. Save your laboratory and return to the experiment whenever you like.
